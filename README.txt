NEXTAG STUDENT WEBSITE
======================

START HERE
1. Extract this ZIP file.
2. Open the NEXTAG folder.
3. Double-click index.html to open the website in your browser.
4. Read CODE-EXPLANATION.md for a file-by-file explanation.

FILES
- index.html: home page
- products.html: product catalog and filters
- brands.html: brand categories
- compare.html: compare up to three products
- about.html: about page
- contact.html: contact form demo
- faq.html: frequently asked questions
- location.html: shop location placeholder
- style.css: shared responsive design
- script.js: interactive features
- CODE-EXPLANATION.md: code explanation list

NOTES
This is a front-end educational demo. Contact/newsletter forms do not send data,
and the site has no real checkout, payment processing, server, or database.
The remote sample images and fonts need an internet connection.
Replace the placeholder contact/location details before publishing.
